# 📊 Sales Data Warehouse & Analytics Project

## 📌 Project Overview

This project focuses on building a complete **Sales Data Warehouse and Analytics solution** using SQL Server. The goal is to transform raw data from multiple business systems into a structured, reliable, and analysis-ready data warehouse and generate meaningful business insights using SQL.

The project covers two key areas:

1. **Data Engineering** – Building and preparing the Data Warehouse
2. **Data Analytics** – Analyzing business data and generating actionable insights

---

## 🏗️ Part 1: Data Warehouse

### 🎯 Objective

Develop a modern SQL Server-based data warehouse to consolidate sales data from different source systems and provide a reliable foundation for analytical reporting and decision-making.

### 📥 Data Sources

The project uses data from two source systems:

- **ERP System** – Provides sales and business-related information
- **CRM System** – Provides customer-related information

The source data is provided in CSV format.

### 🔄 Data Engineering Process

The data engineering process includes:

- Importing data from source systems
- Exploring and profiling the raw data
- Identifying data-quality issues
- Cleaning and standardizing the data
- Transforming the data into an analytical structure
- Integrating ERP and CRM data
- Loading the final data into SQL Server
- Validating the data for accuracy and consistency

### 🧹 Data Quality

Data quality checks are performed to identify and resolve issues such as:

- Missing values
- Duplicate records
- Inconsistent formats
- Invalid values
- Data-type inconsistencies
- Data inconsistencies between source systems

The objective is to ensure that the warehouse contains clean, consistent, and trustworthy data.

### 🔗 Data Integration

ERP and CRM data are integrated into a unified data model so that analysts and business stakeholders can work with a single, consistent source of information.

The project focuses on the latest available dataset, so historical data tracking is not included in the current scope.

---

## 📊 Part 2: Data Analytics & Reporting

### 🎯 Objective

The analytics layer uses SQL to convert warehouse data into meaningful business insights that can support decision-making.

### 🔍 Key Analysis Areas

#### 👥 Customer Behavior

Analysis of customer activity and purchasing patterns, including:

- Identifying high-value customers
- Understanding customer purchasing behavior
- Analyzing customer contribution to revenue
- Comparing customer performance

#### 📦 Product Performance

Analysis of product-level performance, including:

- Top-performing products
- Revenue generated by products
- Product sales volume
- Identifying underperforming products
- Comparing product performance

#### 💰 Sales Trends

Analysis of sales performance over time, including:

- Overall sales performance
- Revenue trends
- Sales by period
- Identifying high-performing periods
- Understanding changes in sales performance

---

## 💡 Business Questions

The project focuses on answering practical business questions such as:

- Which customers generate the highest revenue?
- Which products contribute the most to sales?
- Which products are underperforming?
- How are sales changing over time?
- What are the major sales trends?
- Where are the key opportunities for improving business performance?

Key validation areas include:

- Record counts
- Duplicate checks

- Referential integrity
- Data consistency
- Transformation validation
- Source-to-target comparison
